# ☕ Brew & Bean Coffee Shop

A simple and beginner-friendly coffee shop website created using HTML and CSS.

## 📌 Project Description

Brew & Bean Coffee Shop is a basic static website designed to display information about a coffee shop.

The website includes:
- Coffee shop name and tagline
- Menu items
- Food and drink prices
- Shop address
- Contact number
- Footer with copyright information

## 🛠️ Technologies Used

- HTML5
- CSS3
